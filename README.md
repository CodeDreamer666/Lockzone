# Lockdown-Sector

Lockdown-Sector is a first-person browser shooter set in a compact 40 × 40 industrial combat yard. Survive endless enemy waves, fight through shipping-container lanes and connected tower routes, aim for headshots, and improve your run at the safe-zone shop.

## Features

- Endless waves that begin with 6 enemies, add 2 per wave, and cap at 24
- Fair active-enemy limits of 4, then 5, then 6 from Wave 7 onward
- First-person movement, jumping, aiming, scoped view, and mouse-look controls
- Headshot and body-shot combat with enemy health, player regeneration, and hit feedback
- Unlimited reserve ammunition with a 40-round magazine and manual reloads
- One protected corner shop with repeatable speed, health, rifle-damage, and magazine upgrades
- Solid container cover plus two ramp-accessible platforms connected by a bridge
- Dynamic lighting, shadows, bloom, and sound effects

## Run locally

Install dependencies, then start the Vite development server:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in a browser.

## Controls

- `W`, `A`, `S`, `D` — Move
- `Space` — Jump
- Mouse — Look
- Left click — Fire
- Right click — Aim
- `R` — Reload
- `E` — Open or close the safe-zone shop
- `Esc` — Pause
