# Lockdown-Sector

Lockdown-Sector is a first-person browser shooter set in a compact industrial combat yard. Survive escalating enemy waves, use cover, aim for headshots, manage a 40-round magazine, and make each reload count.

## Features

- Three escalating survival waves with grounded AI opponents
- First-person movement, jumping, aiming, scoped view, and mouse-look controls
- Headshot and body-shot combat with enemy health, player regeneration, and hit feedback
- Unlimited reserve ammunition with a 40-round magazine and manual reloads
- Dynamic lighting, shadows, bloom, sound effects, and an industrial map with cover

## Run locally

Install dependencies, then start the Vite development server:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in a browser.

## Controls

- `W`, `A`, `S`, `D` — Move
- `Space` — Jump
- Mouse — Look
- Left click — Fire
- Right click — Aim
- `R` — Reload
- `Esc` — Pause
