# Asset notes

`public/assets/CesiumMan.glb` is the animated, rigged Cesium Man glTF sample from the Khronos glTF Sample Assets project. It is credited to Cesium and supplied under CC BY 4.0 with trademark limitations. It is used here as a clearly documented prototype placeholder, not as a final commercial character.

Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CesiumMan

The industrial compound, rifle view model, materials, light fixtures, and all audio tones are original code-built prototype content in this repository. Audio is synthesized with the browser Web Audio API, so no third-party sound files are redistributed.

`public/assets/industrial-ground-generated.png` is an original generated material used only as the tiled wet concrete/asphalt base colour for the district ground. It was created for this project with the prompt: "seamless photorealistic weathered concrete and industrial asphalt surface, neutral grey palette, subtle hairline cracks, water stains, oil marks and worn aggregate". It contains no third-party logos, signs, maps, or game-derived artwork.

`public/assets/container-corrugated-weathered.png` is an original generated, neutral corrugated-steel material used by the blue, red, and muted-olive shipping containers. It was created for this project as a flat, tile-friendly, orthographic surface with restrained chipped paint, grime, scratches, edge wear, and subtle rust. The neutral texture is tinted in Babylon.js so all container colours share one coherent industrial material.
