# Audio sources and licensing

All current gameplay audio is generated procedurally at runtime with the browser Web Audio API.

- Author: project implementation
- Source recordings: none
- Third-party audio assets: none
- Licence/attribution obligation: none beyond the project's own licence

The rifle combines a generated high-frequency crack, low-frequency body, mechanical noise burst, and filtered indoor/outdoor tail. Footsteps and landing sounds use generated noise and oscillator layers tuned per surface. No sounds were copied, sampled, or ripped from commercial games.
